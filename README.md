# Документация к плагину "Разметчик операций"

Это расширение для редактора VS Code, созданноев ходе лабораторной работы №3.

**Автор:** Дмитриева Капитолина Олеговна
**Группа:** М3117

## Что делает плагин
Плагин предназначен для построчного анализа исходного кода, ведения статистики (количества операций) и маркировки управляющих конструкций. 

Если выделить фрагмент кода мышкой и вызвать команду из контекстного меню, плагин:
1. Построчно проверит текст на наличие ключевых слов `if`, `for`, `while`, `switch`.
2. Посчитает общее количество таких операций.
3. Выведет всплывающее окно с итоговым количеством найденных элементов.

## Описание структуры кода
Весь исходный код плагина расположен в файле `src/extension.ts` и включает в себя:

- `activate(context)` — основная функция активации плагина. Она считывает выделенный пользователем текст через `editor.document.getText`, с помощью метода `.split('\n')` переводит его в структуру данных "массив строк", запускает цикл анализа и производит замену текста в IDE через объект `editBuilder`.
- `deactivate()` — функция деактивации расширения для корректного освобождения ресурсов оперативной памяти при закрытии редактора.

## Используемые алгоритмы
- **Построчный обход:** Текст разбивается на массив строк, и к каждой строке применяется цикл `for...of`.
- **Регулярные выражения:** Поиск ключевых слов выполняется с помощью `RegExp.prototype.test()`. Использование метасимволов границ слов `\b` (например, `/\bif\b/`) гарантирует защиту от ложных срабатываний на пользовательских переменных, содержащих эти буквы внутри своего имени.
- **Динамический счётчик:** Переменная `operCount` аккумулирует число найденных совпадений на лету и используется для сквозной нумерации операций.
